# PREFLIGHT brand files

**The mark is a runway seen in perspective:** the white threshold stripes and edge lines converging
toward a vanishing point, with the gold centreline dashes running ahead, on a Wayne State green
`#0C5449` tile. It was generated by ChatGPT, and that is the whole provenance story. The mark is
the only thing in this repo that took off without a checklist.

## Colours
| Role | Colour |
|---|---|
| Tile | Wayne State green `#0C5449` |
| Centreline dashes (the only gold) | Wayne State gold `#FFCC33` |
| Runway markings | White `#FFFFFF` |
| Board background | Cream `#F4F1EA` |
| Site accent only, never in the mark | Deep blue `#0E5A7D` |

Gold never sits behind white text.

## The board
`preflight-board.png` is the reference sheet: the primary mark, the app icon, the horizontal and
stacked lockups with the tagline "Every push is cleared for takeoff.", the mark on light and dark
backgrounds, the colour palette, the Lato type scale, the favicon previews, the clear space (a
quarter of the icon width) and the 16 px minimum size, and the do/don't list. When in doubt, the
board is the answer.

## The rule
The mark is generated, not drawn. Nobody redraws it, edits its geometry, or "improves" it by hand.
If a vector is ever needed, trace the PNG with vtracer or potrace; do not redraw it.
